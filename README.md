# Rinterio - Interior Design Website

This responsive interior design website is built using **HTML**, **Tailwind CSS**, and **DaisyUI**. The website showcases modern interior design services, portfolios, and client testimonials. It is designed to be fully responsive and works seamlessly on all devices (desktop, tablet, and mobile).

## Features

- **Responsive Design**: The website is fully responsive and optimized for all screen sizes.
- **Interactive Elements**: Buttons, forms, and cards for user interaction.
- **Sections**:
  - Home: Introduction to Rinterio and its services.
  - About Us: Information about the company and its design philosophy.
  - Portfolio: Showcase of latest projects.
  - Upcoming Projects: Details about new projects under construction.
  - Client Testimonials: Feedback from happy clients.
  - Contact Us: Form to discuss new projects.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
- **DaisyUI**: Tailwind CSS component library for pre-designed components.

## Technologies Used

- **HTML5**: For structuring the website.
- **Tailwind CSS**: For styling and layout.
- **DaisyUI**: For pre-designed components.
- **Font Awesome**: For icons.
- **Google Fonts**: For typography.

## Setup Instructions

1. **Clone the Repository**:
   ```bash
   https://github.com/mdashraful24/my-web-assignments03-repo.git
   cd my-web-assignments03-repo
   ```

2. **Open the Project**:
   - Open the `index.html` file in your browser to view the website.

3. **Customize the Project**:
   - Modify the HTML, Tailwind CSS classes, and JavaScript as needed.
   - Replace placeholder images and text with your own content.

4. **Deploy the Website**:
   - You can deploy the website using platforms like GitHub Pages, Netlify, or Vercel.
